# 观澜：Agent 原生的知识库引擎

观澜（guanlan）是一个把"确定性脚本"和"LLM 工作流"结合起来的知识库引擎。
它的核心设计是三层架构：raw/ 存原始资料（只读）、wiki/ 存知识层（Agent 拥有）、
SCHEMA.md 声明领域约定。

## 核心理念

观澜认为，知识库的"事实来源"应该是不可篡改的原始资料，而"知识层"是 Agent
基于这些资料构建的结构化理解。两者分离，使得知识库可以被任意 Agent 生态使用，
而不绑定到特定的 Agent 运行时。

## Agent 运行时解耦

在最新的重构中，观澜把对 Agentao 运行时的硬耦合收敛到了一个 AgentRuntime 协议后面。
这意味着引擎可以适配任意 Agent 运行时（Claude Code、Codex、通用 HTTP 等），
同时通过两道机制补齐了解耦后的安全漏洞：

1. 硬约束注入：wrapper 在拼 prompt 时强制把行为约束注入头部，不再依赖 Agent 自动读项目级指令文件。
2. 只读路径 raw 快照保护：只读 query 路径在调用前后取 raw 快照比对，任何 raw 改动都判失败。
