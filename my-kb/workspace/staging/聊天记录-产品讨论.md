# 聊天记录：观澜产品讨论

## 时间
2026-06-24

## 参与者
用户 + AI 助手

## 讨论内容

### Q: 观澜如何抽离核心产品？
A: 核心产品 = 不变内核 + Profile 接缝 + Runtime 适配。行业差异下沉到 Profile，
   Agent 差异下沉到适配器，内核一行不动。

### Q: 解耦 Agentao 会有什么约束问题？
A: 事实层安全（raw 不可变）靠确定性机制兜底，不塌；语义层安全（行为约束）
   靠 Agentao 自动注入 AGENTAO.md，解耦后需要 wrapper 强制注入 prompt 头部。

### Q: agent 上下文 md 怎么进知识库？
A: 不能直接进 raw/（会污染事实来源）。先 deposit 到 workspace/staging/，
   人审核后晋级为 raw/ 源，再 ingest 入 wiki/。

## 决策
1. 抽 AgentRuntime 协议，补齐只读路径 raw 快照 + 硬约束注入
2. MCP 加 deposit 工具，写暂存区（非知识库本体）
3. 暂存区加入 Web workspace 白名单，人可审核晋级
