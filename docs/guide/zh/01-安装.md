# 安装

## 环境要求

- **Python 3.10+**。
- 核心命令（`init` / `check` / `health` / `lint` / `graph` / `reindex` / `search`）**零 LLM、可离线运行**，不需要任何模型或网络。
- `ingest` / `query` 以及 Web 端问答需要**配置一个 Agent 运行时**（见下「Agent 运行时」）。
- `convert` 从观澜这一侧看也是零 LLM，但它会**外调** `pdf-to-markdown` 技能的转换后端（MinerU / marker / pypdf），真正跑一次转换需至少装好其中一个后端。

## Agent 运行时

`ingest` / `query` / `ask` 这三个"要思考"的入口需要 Agent 运行时驱动 LLM。观澜通过 `AgentRuntime` 协议解耦，支持两种运行时：

### 默认：Agentao（CLI 子进程）

```bash
pip install 'guanlan-wiki[mcp]'   # 带入 agentao + mcp SDK
```

`agentao run` 子进程驱动，自动读 `AGENTAO.md` 注入行为约束。无需额外配置，装好 agentao 并在 PATH 即可。

### 可选：OpenAI SDK（不依赖 Agentao）

```bash
pip install guanlan-wiki openai
export GUANLAN_RUNTIME=openai
export OPENAI_API_KEY=sk-...
guanlan -C my-wiki ingest raw/x.md --model gpt-4o-mini
```

用 OpenAI 兼容 API 的 tool calling 跑一个最小 agent loop，替代 `agentao run`。支持任何 OpenAI 兼容端点：

```bash
export OPENAI_BASE_URL=http://localhost:11434/v1   # Ollama / vLLM / 其他兼容服务
guanlan -C my-wiki query "你的问题" --model qwen2.5:14b
```

**运行时选择**：环境变量 `GUANLAN_RUNTIME`（默认 `agentao`；设 `openai` 走 OpenAI SDK）。两种运行时共享同一套硬约束注入和 raw 快照保护，安全模型一致。

## 安装核心包

```bash
pip install guanlan-wiki
```

> PyPI 发布名是 `guanlan-wiki`（裸名 `guanlan` 已被一个无关项目占用）；安装后**命令行与导入名仍是 `guanlan`**。

验证：

```bash
guanlan --version     # 应打印当前版本（如 0.1.9）
guanlan --help
```

## 可选宿主（叠加层，按需安装）

观澜的核心是 CLI；Web 与 MCP 宿主是**可选叠加层**，不装也能用全部 CLI 命令。

### Web 宿主

```bash
pip install 'guanlan-wiki[web]'
```

带入可选依赖：`fastapi` / `uvicorn` / `markdown` / `python-multipart` / `anyio`。装完才有 `guanlan web`，详见 [Web 宿主](05-web-宿主.md)。

### MCP 宿主

```bash
pip install 'guanlan-wiki[mcp]'
```

带入官方 `mcp` SDK（`mcp>=1.27,<2`）与 `anyio`。装完才有 `guanlan mcp`，详见 [MCP 宿主](06-mcp-宿主.md)。

> 两个 extra 都是「**没装就优雅降级**」：未安装对应依赖时,运行 `guanlan web` / `guanlan mcp` 会给出明确的「请 `pip install 'guanlan-wiki[...]'`」提示,而非崩溃。

## 从源码开发安装

仓库用 [`uv`](https://github.com/astral-sh/uv) 管理依赖:

```bash
git clone <repo-url>
cd guanlan
uv run guanlan --help     # 直接在项目环境里跑 CLI
uv run pytest             # 跑测试
```

开发模式下,仓库根**自身就是一个样例 wiki**,维护引擎 `skills/guanlan-wiki/` 会命中 Agentao 的 repo-root 技能发现路径(`<工作目录>/skills/`),**免安装**。详见仓库根 [`CLAUDE.md`](../../../CLAUDE.md) 的「Two run modes」。
